# Restitutions des modèles

Vues Markdown générées depuis les JSON : [release](release.md), [backlog](backlog.md) et [panorama As Is](panorama-as-is.md). Elles ne font pas autorité pour modifier le modèle.

Après modification des JSON, exécuter `python scripts/render_models.py` à la racine du projet. Les analyses et insights restent dans `connaissance/` et `marche/`. L’exploration interactive est disponible dans [FLOW Atlas](../app/README.md).

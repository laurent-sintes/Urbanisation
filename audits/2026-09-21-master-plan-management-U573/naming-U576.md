# Nom proposé — U576

**Plan Implementation — mise en œuvre du plan.** Mettre en œuvre les recommandations autorisées du plan en mobilisant les capacités responsables et en vérifiant les effets effectivement pris en compte.

Le regroupement présenté en U575 est accepté dans son principe. Laurent refuse le nom Master Plan Application : Master est déjà porté par l’Area et Application évoquerait une application informatique. Aucun nom de remplacement n’est adopté à ce stade.

Plan Implementation est proposé pour décrire le passage des recommandations retenues aux effets pris en compte. Plan Execution peut englober la réalisation physique ; Plan Release peut être compris comme la transmission seule. Ces appréciations sont des choix éditoriaux FLOW.

Oracle utilise historiquement « Revise and Implement Plan Recommendations » dans sa description des processus de Value Chain Planning (ELM593). Microsoft Business Central documente Carry Out Action Message (ELM594), avec création ou transmission des suites appropriées. Appui lexical historique et rapprochement fonctionnel, pas consensus sur un intitulé identique. Titres, versions, liens et limites sont conservés dans [l’annexe](../../modeles/backlog/master-plan-application-U575.yaml), section naming_review_U576.

Les six comportements, catégories d’effets et responsabilités restent identiques. Aucun changement canonique ou de publication.
